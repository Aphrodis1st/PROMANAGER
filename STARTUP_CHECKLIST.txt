FOLLOW THESE STEPS IN ORDER:

┌────────────────────────────────────────────────────────────────┐
│ STEP 1: START BACKEND SERVER                                  │
└────────────────────────────────────────────────────────────────┘

   □ Double-click: start-backend.bat
   
   □ Wait for this message:
     "✅ Server ready to accept connections"
   
   □ Verify by opening browser:
     http://localhost:5000
     
     Should show: {"message": "ProManager API Server", "status": "running"}

┌────────────────────────────────────────────────────────────────┐
│ STEP 2: INITIALIZE CURRENCIES (First Time Only)               │
└────────────────────────────────────────────────────────────────┘

   □ Double-click: initialize-currencies.bat
   
   □ Wait for success message
   
   □ This creates 10 default currencies in your system

┌────────────────────────────────────────────────────────────────┐
│ STEP 3: START FRONTEND (If Not Already Running)               │
└────────────────────────────────────────────────────────────────┘

   □ Open new terminal/command prompt
   
   □ Run:
     cd frontend
     npm run dev
   
   □ Access: http://localhost:5173

┌────────────────────────────────────────────────────────────────┐
│ STEP 4: VERIFY EVERYTHING WORKS                               │
└────────────────────────────────────────────────────────────────┘

   □ Backend running: http://localhost:5000 ✓
   
   □ Frontend running: http://localhost:5173 ✓
   
   □ Can login to Stock: http://localhost:5173/stock/login ✓
   
   □ Can login to Hospital: http://localhost:5173/hospital/login ✓
   
   □ No connection errors ✓

❌ TROUBLESHOOTING:

   Problem: Connection refused error
   Solution: Backend not running → Run start-backend.bat
   
   Problem: Port already in use
   Solution: Kill process or change port in .env files
   
   Problem: npm command not found
   Solution: Install Node.js from https://nodejs.org
   
   Problem: Dependencies missing
   Solution: Run "npm install" in backend and frontend folders
