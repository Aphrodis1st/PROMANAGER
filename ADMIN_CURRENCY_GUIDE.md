# Stock Currency Settings - Admin Quick Start Guide

## 🎯 Overview
The stock module now supports professional currency management. As an admin, you can set the currency for your entire stock organization, and it will automatically apply to all transactions.

## 📍 How to Set Currency

### Step 1: Navigate to Settings
1. Login to your stock management system
2. Click on **Settings** in the sidebar
3. Select the **Currency Settings** tab

### Step 2: Select Your Currency
Choose from 10+ supported currencies:
- 🇺🇸 **USD** - US Dollar ($)
- 🇪🇺 **EUR** - Euro (€)
- 🇬🇧 **GBP** - British Pound (£)
- 🇯🇵 **JPY** - Japanese Yen (¥)
- 🇨🇳 **CNY** - Chinese Yuan (¥)
- 🇮🇳 **INR** - Indian Rupee (₹)
- 🇦🇪 **AED** - UAE Dirham (د.إ)
- 🇸🇦 **SAR** - Saudi Riyal (ر.س)
- 🇨🇦 **CAD** - Canadian Dollar (C$)
- 🇦🇺 **AUD** - Australian Dollar (A$)

### Step 3: Save Settings
1. Click **Save Currency Settings**
2. Currency will apply immediately across all pages
3. No need to refresh - changes are instant!

## 🔄 Changing Currency

### Can I change currency later?
Yes! You can change currency anytime:
1. Go to Settings → Currency Settings
2. Select new currency
3. Click Save
4. All future transactions will use the new currency

### What happens to old transactions?
- Old transactions keep their original amounts
- Only the display symbol changes
- No data is lost or modified
- Historical records remain accurate

## 💡 Best Practices

### ✅ DO:
- Set currency before entering transactions
- Use your local business currency
- Keep currency consistent for accounting
- Change currency only when necessary

### ❌ DON'T:
- Change currency frequently
- Use different currencies for same organization
- Forget to inform your team about currency changes

## 🆘 Troubleshooting

### Currency not showing?
1. Check if you saved the settings
2. Verify you're logged in as admin
3. Clear browser cache and reload

### Wrong currency displaying?
1. Go to Settings → Currency Settings
2. Verify correct currency is selected
3. Click Save again

### Currency symbol looks wrong?
- This is normal for some currencies
- Symbol depends on your browser/system fonts
- Functionality is not affected
