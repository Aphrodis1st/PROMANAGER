## 8. Monthly Tax Process Flow

```
┌─────────────────────────────────────────────────────────────┐
│                 MONTHLY TAX PROCESS FLOW                     │
└─────────────────────────────────────────────────────────────┘

    Week 1-4: Daily Operations
    ┌──────────────────────────────┐
    │ • Record Sales (Output Tax)  │
    │ • Record Purchases (Input)   │
    │ • Verify Tax Calculations    │
    └──────────┬───────────────────┘
               │
               ▼
    Month End: Reconciliation
    ┌──────────────────────────────┐
    │ • Run Tax Reports            │
    │ • Review Transactions        │
    │ • Check VAT Reconciliation   │
    │ • Verify GL Accounts         │
    └──────────┬───────────────────┘
               │
               ▼
    Week 1 Next Month: Filing
    ┌──────────────────────────────┐
    │ • Prepare Tax Return         │
    │ • Calculate Net Tax          │
    │ • Submit to Tax Authority    │
    │ • Make Payment               │
    └──────────┬───────────────────┘
               │
               ▼
    Week 2 Next Month: Recording
    ┌──────────────────────────────┐
    │ • Record Payment Entry       │
    │ • Clear VAT Control Account  │
    │ • Archive Tax Records        │
    │ • Update Next Period         │
    └──────────────────────────────┘
```

## 10. Tax Calculation Examples

```
┌─────────────────────────────────────────────────────────────┐
│              TAX CALCULATION EXAMPLES                        │
└─────────────────────────────────────────────────────────────┘

Example 1: Tax-Exclusive (Standard)
┌────────────────────────────────┐
│ Net Amount:        $100.00     │
│ Tax Rate:          15%         │
│ Tax Amount:        $15.00      │
│ ─────────────────────────────  │
│ Gross Amount:      $115.00     │
└────────────────────────────────┘

Example 2: Tax-Inclusive
┌────────────────────────────────┐
│ Gross Amount:      $115.00     │
│ Tax Rate:          15%         │
│ Net Amount:        $100.00     │
│ Tax Amount:        $15.00      │
│ ─────────────────────────────  │
│ Formula: 115 / 1.15 = 100      │
└────────────────────────────────┘

Example 3: Multiple Taxes
┌────────────────────────────────┐
│ Net Amount:        $100.00     │
│ VAT 15%:           $15.00      │
│ Excise 5%:         $5.00       │
│ ─────────────────────────────  │
│ Total Tax:         $20.00      │
│ Gross Amount:      $120.00     │
└────────────────────────────────┘

Example 4: VAT Reconciliation
┌────────────────────────────────┐
│ Output Tax (Sales):  $1,500    │
│ Input Tax (Purch):   $800      │
│ ─────────────────────────────  │
│ Net Payable:         $700      │
│ Status:              TO PAY    │
└────────────────────────────────┘
```
