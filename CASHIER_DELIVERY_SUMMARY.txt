📊 API ENDPOINTS
═════════════════════════════════════════════════════════════════════════════

POST   /api/v1/stock/cashier/complete-sale     → Process completed sale
GET    /api/v1/stock/cashier/shift-sales       → Get shift sales data
POST   /api/v1/stock/cashier/hold-sale         → Save incomplete sale
PUT    /api/v1/stock/cashier/recall-sale/:id   → Retrieve held sale
GET    /api/v1/stock/cashier/held-sales        → List all held sales
GET    /api/v1/stock/cashier/receipt/:id       → Generate receipt
POST   /api/v1/stock/cashier/end-shift         → End shift summary


🚀 QUICK START GUIDE
═════════════════════════════════════════════════════════════════════════════

1. BACKEND SETUP
   cd backend
   npm start
   (Cashier API will be available at /api/v1/stock/cashier)

2. FRONTEND SETUP
   cd stock_manager
   npm run dev
   (Frontend will run on http://localhost:3000)

3. ACCESS CASHIER PAGE
   Navigate to: http://localhost:3000/stock/cashier
   (Make sure you're logged in as a stock user)

4. BASIC WORKFLOW
   • Browse and add products to cart
   • Adjust quantities as needed
   • Select payment method
   • Enter paid amount
   • Click "COMPLETE PAYMENT"
   • Print receipt if needed
